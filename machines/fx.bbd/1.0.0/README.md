# BBD 1.0.0

A bucket-brigade style analog delay as a send effect (Plugin API 3): free or tempo-synced time, feedback, wow and flutter, tone in the loop.

- Id: `fx.bbd`, kind: effect (a send effect on the Rytm's UFX slots)
- Boards: Pi 4 and Pi 5 (the same RMPA package; one file per board here)
- Plugin API: 3
- Licence: MIT
- Source: https://github.com/trigcondition/sidecar-firmware (`plugins/ufx_bbd`)

## Knobs

- Time (TIME)
- Feedback (FDBK)
- Wow/Flutter (W/F)
- Tone (TONE)
