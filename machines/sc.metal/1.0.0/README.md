# METAL 1.0.0

Metallic FM percussion with three sine operators and inharmonic ratio sets: bells, cowbells, clanks.

- Id: `sc.metal`, kind: machine
- Boards: Pi 4 and Pi 5 (the same RMPA package; one file per board here)
- Plugin API: 2
- Licence: MIT
- Source: https://github.com/trigcondition/sidecar-firmware (`plugins/sc_metal`)

## Knobs

- Tune (TUN)
- Ratio (RAT)
- FM Index (IDX)
- Index Decay (IDC)
- Pitch Drop (DRP)
- Decay (DEC)
- Tone (TON)
- Level (LEV)
- Feedback (FB)
- Inharmonic (INH)
