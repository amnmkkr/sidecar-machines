# GRAIN 1.0.0

A granular texture over a built-in sample: position, spray, size, density, pitch, spread and reverse.

- Id: `sc.grain`, kind: machine
- Boards: Pi 4 and Pi 5 (the same RMPA package; one file per board here)
- Plugin API: 2
- Licence: MIT AND CC0-1.0
- Source: https://github.com/trigcondition/sidecar-firmware (`plugins/sc_grain`)

## Knobs

- Position (POS)
- Spray (SPR)
- Grain Size (SIZ)
- Density (DEN)
- Pitch (PIT)
- Spread (SPD)
- Reverse (REV)
- Level (LEV)
- Attack (ATK)
- Release (REL)
- Tone (TON)
