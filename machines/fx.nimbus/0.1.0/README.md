# NIMBUS 0.1.0

A big ambient reverb with an ensemble pad that follows the harmony of what is sent to it. A send effect (Plugin API 3).

- Id: `fx.nimbus`, kind: effect (a send effect on the Rytm's UFX slots)
- Boards: Pi 4 and Pi 5 (the same RMPA package; one file per board here)
- Plugin API: 3
- Licence: MIT
- Source: https://github.com/trigcondition/sidecar-firmware (`plugins/ufx_nimbus`)

## Knobs

- Decay (DCY)
- Ensemble (ENS)
- Tone (TONE)
- Modulation (MOD)
