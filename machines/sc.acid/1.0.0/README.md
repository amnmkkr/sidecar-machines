# ACID 1.0.0

A 303-style bass voice: polyBLEP saw/square into a four-pole ladder with envelope mod, accent, slide and drive.

- Id: `sc.acid`, kind: machine
- Boards: Pi 4 and Pi 5 (the same RMPA package; one file per board here)
- Plugin API: 2
- Licence: MIT
- Source: https://github.com/trigcondition/sidecar-firmware (`plugins/sc_acid`)

## Knobs

- Tune (TUN)
- Saw>Square (WAV)
- Cutoff (CUT)
- Resonance (RES)
- Env Mod (ENV)
- Decay (DEC)
- Accent (ACC)
- Level (LEV)
- Slide Time (SLD)
- Drive (DRV)
- Amp Decay (ADC)
