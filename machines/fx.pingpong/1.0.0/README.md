# PINGPONG 1.0.0

A tempo-synced stereo ping-pong delay as a send effect (Plugin API 3), the example effect of the plugin API.

- Id: `fx.pingpong`, kind: effect (a send effect on the Rytm's UFX slots)
- Boards: Pi 4 and Pi 5 (the same RMPA package; one file per board here)
- Plugin API: 3
- Licence: MIT
- Source: https://github.com/trigcondition/sidecar-firmware (`plugins/ufx_pingpong`)

## Knobs

- Time (TIM)
- Feedback (FDB)
- Tone (TON)
- Width (WID)
