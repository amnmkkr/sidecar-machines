# SNARE 1.0.0

A snare and noise drum designer: tuned body oscillators with a pitch envelope plus shaped noise.

- Id: `sc.snare`, kind: machine
- Boards: Pi 4 and Pi 5 (the same RMPA package; one file per board here)
- Plugin API: 2
- Licence: MIT
- Source: https://github.com/trigcondition/sidecar-firmware (`plugins/sc_snare`)

## Knobs

- Tune (TUN)
- Body Decay (BDC)
- Pitch Env (PEN)
- Noise Tone (NTN)
- Noise Decay (NDC)
- Snap (SNP)
- Body<>Noise (BAL)
- Level (LEV)
- Body Ratio (BRT)
- Noise Reso (NRS)
