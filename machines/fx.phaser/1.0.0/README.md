# PHASER 1.0.0

A stereo phaser as a send effect (Plugin API 3): free or tempo-synced sweep, depth, feedback, 4/6/8 stages with stereo spread.

- Id: `fx.phaser`, kind: effect (a send effect on the Rytm's UFX slots)
- Boards: Pi 4 and Pi 5 (the same RMPA package; one file per board here)
- Plugin API: 3
- Licence: MIT
- Source: https://github.com/trigcondition/sidecar-firmware (`plugins/ufx_phaser`)

## Knobs

- Rate (RATE)
- Depth (DPTH)
- Feedback (FDBK)
- Stages/Sprd (SPRD)
