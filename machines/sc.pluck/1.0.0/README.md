# PLUCK 1.0.0

A Karplus-Strong plucked string with damping, stiffness and body.

- Id: `sc.pluck`, kind: machine
- Boards: Pi 4 and Pi 5 (the same RMPA package; one file per board here)
- Plugin API: 2
- Licence: MIT
- Source: https://github.com/trigcondition/sidecar-firmware (`plugins/sc_pluck`)

## Knobs

- Tune (TUN)
- Decay (DEC)
- Damping (DMP)
- Colour (COL)
- Pick Pos (POS)
- Body (BOD)
- Stretch (STR)
- Level (LEV)
